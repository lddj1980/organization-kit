# Brief - 0001-build-website
**Kit:** website-kit v2.0.0
**Created:** 2026-06-29

## What you need to do

Builds or modifies websites from organization specifications.

## Required inputs (in request/)

- constitution.md
- brand.md
- audience.md
- website-spec.md

## Expected outputs (deliver in response/)

- website/
- documentation/
- tests/
- report.md

## Acceptance criteria

- all required pages implemented
- responsive layout
- SEO metadata present
- brand voice respected
- accessibility considered
- implementation report included
- strategic alignment checked

## How to return the delivery

1. Complete all expected outputs in the response/ folder.
2. Write response/report.md documenting what was built and key decisions.
3. Notify the framework that the work-package is ready for review.
