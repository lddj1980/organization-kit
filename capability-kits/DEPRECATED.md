# DEPRECATED

Esta pasta foi movida para `examples/capability-kits/`.

## Motivo

Na arquitetura atual do Organization Kit, Capability Kits são **externos**.
O Organization Kit não contém implementações reais desses kits.

Os contratos canônicos ficam em `contracts/`.

## O que fazer

- Para ver exemplos conceituais de kits: `examples/capability-kits/`
- Para contratos formais: `contracts/`
- Para implementar um kit real: crie um repositório separado seguindo os contratos em `contracts/`

## Cronograma

- Esta pasta será removida na versão 3.0.0.
