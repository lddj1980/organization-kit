# Luna Waves — Example Organization Project

This is an example of a complete organization project created with the Organization Kit framework.

## About Luna Waves

Luna Waves is an independent music project that creates intimate, reflective electronic music for authentic connection.

## Structure

```
luna-waves/
├── constitution.md              # The center of the organization
├── knowledge/                   # Organizational knowledge
├── memory/                      # History and learning
├── specifications/              # Work specifications
├── work-packages/               # Work packages
├── artifacts/                   # Accepted artifacts
├── state/                       # Current state
└── workspace/                   # Current work space
```

## How It Was Created

```bash
# 1. Initialize the organization
/org.init Luna Waves

# 2. Discover brand and audience
/org.discover brand
/org.discover audience

# 3. Create specifications
/org.spec website
/org.spec content

# 4. Invoke capability kits
/org.invoke website-kit

# 5. Review and accept
/org.review wp-2026-001
/org.accept wp-2026-001

# 6. Learn and evolve
/org.learn
/org.evolve
```

## Key Documents

- [constitution.md](constitution.md) — The source of truth for Luna Waves
- [knowledge/](knowledge/) — Brand guidelines, audience profiles, content strategy
- [memory/](memory/) — Decisions, history, lessons learned
- [state/](state/) — Current capabilities, roadmap, health status
