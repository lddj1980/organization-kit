# Website Kit

Especialista em presença digital.

## O que este kit faz

O Website Kit transforma a identidade de uma organização em uma presença digital coerente.

Não constrói sites.
Constrói a manifestação digital de uma organização.

## Capacidades

- Arquitetura de informação (estrutura e hierarquia de páginas)
- Estratégia de conteúdo para web (o que falar, onde, como)
- Copywriting para páginas-chave (home, about, manifesto)
- Especificação técnica para desenvolvimento
- Revisão de coerência (identidade vs. presença digital)

## O que este kit NÃO faz

- Não desenvolve código (isso é competência humana ou outro kit)
- Não cria identidade visual (isso é o Visual Kit)
- Não escreve blog posts (isso é o Content Kit)
- Não otimiza para SEO (isso é o SEO Kit)

## Tipos de Work Package que aceita

- `site-architecture` — estrutura e hierarquia do site
- `page-copy` — copy para uma página específica
- `content-strategy` — estratégia de conteúdo para o site
- `site-review` — revisão de coerência do site existente
