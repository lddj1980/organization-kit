# Convenções do Protocol

## Hierarquia de autoridade

Em qualquer conflito de interpretação, a precedência é:

1. Constitution da organização
2. EKP (este protocolo)
3. Manifesto do framework
4. Documentos de especificação
5. Work Packages individuais

## Regras de ouro

- Nenhum trabalho começa sem uma Constitution válida
- Nenhum Capability Kit escreve diretamente na memory ou state
- Todo Work Package referencia explicitamente a Constitution vigente
- Review estratégico é obrigatório — não é opcional
- Artefatos rejeitados não afetam a memória da organização
