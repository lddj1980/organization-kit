# spec-website

Skill for authoring website specifications in the Organization Kit.

## When to use

Use this skill when the user wants to specify a website — either a new site or an evolution of an existing `website` Living Artifact.

## Entry point

Read `prompt.md` for the specification dimensions, then follow `workflow.md` for the contract-driven process.

## Files

- `prompt.md` — dimensions to consider when specifying a website
- `workflow.md` — contract-driven workflow
- `examples/` — example specifications
- `input-schema.json` / `output-schema.json` — schemas for validation
- `acceptance.md` — acceptance criteria
- `tests/` — test cases
