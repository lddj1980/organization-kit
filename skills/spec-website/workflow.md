# Workflow — spec-website (Contract-Driven)

1. **Identify which capability kit this is for**
2. **Load contracts/<kit-name>/contract.yaml**
3. **From contract.required_inputs**, determine what spec documents need to be created
4. **For each required_input of type spec**, create a corresponding spec document
5. **Write spec following contract-derived structure**

The contract's acceptance criteria become the spec's acceptance criteria.
