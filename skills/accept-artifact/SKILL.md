# accept-artifact

Skill for accepting Work Packages and promoting their artifacts into the organization.

## When to use

Use this skill after a Work Package has been reviewed and approved. It covers both `living` artifacts (evolutionary) and `immutable` artifacts (historical).

## Entry point

Follow `workflow.md` for the full acceptance process and state updates.

## Files

- `workflow.md` — acceptance workflow and state changes
- `prompt.md` — prompts for acceptance decisions
- `examples/` — example acceptance outputs
- `input-schema.json` / `output-schema.json` — schemas for validation
- `acceptance.md` — acceptance criteria
- `tests/` — test cases
