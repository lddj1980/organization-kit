# Deprecated: framework/commands/

This directory is **deprecated** as of Organization Kit v1.0.

## Canonical source of commands

The canonical source for all framework commands is:

```text
commands/
```

Edits to commands should be made in `commands/` first. Other locations are generated or adapted from there.

## Other command locations

- `.claude/commands/` — installed/adapted copy for Claude Code. Generated from `commands/`.
- `.github/prompts/`, `.cursor/rules/`, `.kimi-code/skills/`, etc. — adapter-specific copies generated by `setup.ps1`.

## What changed

Previously `framework/commands/` was used as the source for setup scripts. This created ambiguity about which file to edit. v1.0 consolidates the canonical source to `commands/`.

If you are maintaining a command, edit `commands/org.{name}.md`.
