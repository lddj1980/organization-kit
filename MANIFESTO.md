# Manifesto
## Purpose Organization Framework

---

### Por que este framework existe

Hoje a maior parte das ferramentas de IA ajuda a construir artefatos.

Um artigo.
Um site.
Uma imagem.
Um vídeo.
Um código.

Isso é útil. Mas é insuficiente.

Porque artefatos não têm memória.
Artefatos não têm propósito.
Artefatos não sabem quem os criou, por que foram criados, ou para onde estão indo.

O resultado é que organizações que dependem de IA para produzir conteúdo acabam produzindo muito mais, mas com muito menos coerência. A identidade se dilui. A voz se fragmenta. A missão se perde no volume.

Este framework existe para resolver esse problema.

---

### O que acreditamos

**Acreditamos que toda organização possui uma identidade que precisa ser preservada.**

Não importa quantas ferramentas, IAs ou colaboradores estejam envolvidos.
A identidade é o fio condutor que une cada decisão, cada criação, cada evolução.

**Acreditamos que propósito é a única bússola confiável.**

Não a tecnologia.
Não a tendência do mercado.
Não a ferramenta mais recente.

Quando o propósito é claro, qualquer decisão pode ser avaliada de forma objetiva:
*Isso nos aproxima ou nos afasta de quem queremos ser?*

**Acreditamos que organizações são seres vivos, não projetos.**

Projetos terminam.
Organizações evoluem.

Um framework que trata uma organização como projeto está condenado a reiniciar do zero cada vez que uma fase termina.
Um framework que trata uma organização como ser vivo preserva memória, aprende com o passado, e evolui de forma coerente.

**Acreditamos que a IA é infraestrutura, não protagonista.**

A IA não é o centro da experiência.
As pessoas são.

A IA existe para ampliar a capacidade humana de criar, conectar, e comunicar com coerência.
Quando a IA se torna protagonista, a organização perde sua voz.

**Acreditamos que capacidades precedem ativos.**

Um site não é uma capacidade.
É um ativo — a manifestação de uma capacidade de presença digital.

Um álbum não é uma capacidade.
É um ativo — a manifestação de uma capacidade musical.

Quando pensamos primeiro em capacidades, os ativos surgem de forma natural e coerente.
Quando pensamos primeiro em ativos, construímos artefatos sem propósito.

---

### O que este framework não é

Não é um framework para construir sites.
Não é um framework de agentes de IA.
Não é um conjunto de prompts.
Não é uma ferramenta de produtividade.

---

### O que este framework é

É um sistema para modelar organizações digitais desde sua identidade até sua evolução contínua.

Ele permite que uma organização:

- defina quem é, por que existe e para onde vai
- preserve sua identidade ao longo do tempo e das ferramentas
- tome decisões coerentes com seu propósito
- produza ativos que fortalecem, não fragmentam, sua missão
- aprenda continuamente e evolua sem perder o fio condutor

---

### Para quem é este framework

Para criadores que constroem organizações com propósito claro.
Para times que precisam de coerência mais do que de volume.
Para projetos que atravessam anos, não sprints.
Para qualquer pessoa que acredita que o que você faz importa menos do que por que você faz.

---

### Como sabemos que estamos no caminho certo

Quando uma organização que usa este framework conseguir responder, a qualquer momento:

- *Quem somos?*
- *Por que existimos?*
- *O que faz sentido produzir agora?*
- *Como manter coerência ao longo dos anos?*

Então o framework está cumprindo seu propósito.

## Como este manifesto se traduz em arquitetura

### Constitution First
Todo comando, skill e contrato consulta a Constitution antes de agir.
Nenhuma decisão é tomada sem referência à identidade da organização.

### Propósito antes de produtividade
Work packages são avaliados por contribuição ao propósito, não por volume de entrega.
Revisão estratégica sempre precede aceite técnico.

### IA como infraestrutura
O framework usa IA para amplificar coerência, não para substituir decisão humana.
Skills orientam, não executam. Revisão estratégica é sempre validada pelo usuário.

### Capacidades antes de ativos
O framework modela capacidades (website, content, music) antes de produzir ativos.
Cada work package exercita uma capacidade específica.

### Coerência organizacional
Memory preserva decisões e aprendizados.
State reflete o estado atual da organização.
Health avalia maturidade em múltiplas dimensões.
